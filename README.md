# Algorithms and Data Structures

Coursework and implementations from **1DL210 – Algorithms and Data Structures I** at Uppsala University.

This repository contains my work throughout the course, including implementations of algorithms, runtime experiments, and complexity analysis.

## Assignments

### Assignment 1 — Sorting Algorithms

Implementations and analysis of:

- Insertion Sort
- Selection Sort
- Sink Sort
- Runtime comparisons
- Runtime approximations

This assignment was completed as group work. Individual contributions are documented in the notebook.

### Assignment 2 — Efficient Sorting Algorithms

Implementations and analysis of:

- Merge Sort
- Quick Sort
- Heap Sort
- Runtime comparisons
- Comparison of `n²` and `n log n` runtime behaviour
